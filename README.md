# CodeAlpha Machine Learning Projects

This repository contains the machine learning projects completed as part of the CodeAlpha Machine Learning Internship.

## Projects

### 1. Credit Scoring Model
A machine learning classification project that predicts the likelihood of credit card default based on customer financial and repayment history.

**Techniques:** Logistic Regression, Decision Tree, Random Forest, class balancing, model evaluation and feature importance analysis.

### 2. Disease Prediction
A machine learning model for predicting heart disease using patient health data.

**Model:** Random Forest Classifier

### 3. Handwritten Character Recognition
A deep learning project for recognizing handwritten characters using a Convolutional Neural Network (CNN).

**Model:** CNN

## Technologies Used

- Python

- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- TensorFlow / Keras
- Jupyter Notebook
